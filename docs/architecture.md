# 시스템 구조

## 현재 상태

이 문서는 구현 예정인 구조를 설명한다.
현재는 개발 환경과 패키지 기본 실행을 구성한다.

## 문서 처리 흐름

```text
출처 목록
→ 문서 다운로드
→ 중복·버전 확인
→ 본문·표·페이지 추출
→ 청크 생성
→ 검색 인덱스 저장
```

## 질문 처리 흐름

```text
사용자 질문
→ 키워드·벡터 검색
→ 검색 결과 결합
→ 재정렬
→ 근거 선택
→ LLM 답변 생성
→ 인용 검증
→ 답변과 출처 반환
```

## 데이터 구분

| 데이터 | 주요 내용 | 위치 |
| --- | --- | --- |
| 출처 목록 | 문서 ID, 제목, URL, 버전 | data/manifests |
| 원문 | 다운로드한 파일 | data/raw |
| 추출 결과 | 본문, 표, 페이지 | data/processed |
| 검색 인덱스 | 검색에 필요한 표현과 메타데이터 | data/indexes |
| 평가 데이터 | 질문, 정답, 원문 근거 | evals |
| 실험 결과 | 설정, 지표, 실패 분석 | reports |

## 설계 원칙

- 문서 ID와 버전, 페이지 정보를 처리 과정에서 유지한다.
- 코드와 설정, 원문 데이터를 구분한다.
- 검색과 답변 생성의 실패를 따로 분석한다.
- 평가 결과에 데이터·모델·설정·커밋 정보를 기록한다.
- 특정 DB나 모델은 비교 후 선택하고 이유를 남긴다.
