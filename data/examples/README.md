## 사용 순서

1. 위 표에 있는 Markdown 문서 5개만 검색 대상에 넣는다. 전체 디렉터리 재귀 수집은 하지 않는다.
2. 문서 앞머리의 document_id·version·language를 메타데이터로 보존한다. Markdown은 페이지 번호를 만들지 말고 문서 ID와 제목/절을 근거로 사용한다.
3. 최신 버전 질문과 버전 지정 질문을 구분한다. 기본 문자열 정렬로 버전 순서를 결정하지 않는다.
4. [확인 질문 12개](example_questions.jsonl)를 별도로 읽어 답변과 근거를 확인한다. 이 파일과 이 README는 검색·임베딩 대상에서 제외한다. 정답이 검색되면 평가가 오염된다.
5. 제공된 질문은 개발 중 동작 확인용이다. 실제 성능 보고에는 별도의 미공개 평가 질문과 평가 방법이 필요하다.

현재 이 폴더를 자동 색인하는 기능을 추가한 것은 아니다. 기존 파이프라인을 연결할 때 위 규칙을 적용한다.

## 이용 범위

외부 원문을 포함하지 않는 프로젝트 자체 예제다. 제3자 자료의 이용 허가와 별개로 관리한다. 이 작업에서는 프로젝트 라이선스를 새로 선택하거나 변경하지 않았다. 이 설명 자체가 별도의 공개 라이선스 부여를 뜻하지 않는다.

전체 선정 기준은 [data_sources.md](../../docs/data_sources.md), 외부 자료 이용 조건은 [data_usage_review.md](../../docs/data_usage_review.md)를 참고한다.
